# Sumber panduan keselamatan

Versi: `bnpb-safety-2026-11-03`. Ditinjau 3 November 2026.

Balasan tetap mengutamakan tempat aman, mengurangi paparan asap, dan mengikuti
petugas. Pengguna tidak diminta mendekati api untuk mengumpulkan bukti. Api besar
tidak boleh ditangani seorang diri. Panduan ini merangkum
[imbauan BNPB, 8 Oktober 2026](https://www.bnpb.go.id/berita/perkembangan-situasi-dan-penanganan-bencana-di-tanah-air-8-oktober-2026).

Saat ancaman jiwa disebut, bot mengarahkan pengguna menghubungi layanan darurat
resmi secara langsung. Nomor lokal tidak ditebak. Konfigurasi kontak harus
memiliki nomor, sumber HTTPS dan waktu verifikasi operator. Balasan bot tidak
menyatakan petugas telah berangkat atau insiden ditutup resmi.
